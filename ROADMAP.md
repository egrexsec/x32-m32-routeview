# Roadmap

## Near term

- expand parser coverage across currently summarized categories
- improve production-sheet exports and print readability
- strengthen route graph explanations and troubleshooting flows
- refine demo data and documentation for volunteer onboarding

## Mid term

- scene comparison / diff workflow
- stronger routing-map visual layers
- more export presets for handoff packets and print packages
- better parser diagnostics for partially supported commands

## Longer term

- multi-scene comparison primitives
- broader console-family support if the data model stays clean
- collaboration and packaging features that do not compromise the tool’s operator-first design
